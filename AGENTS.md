# EzzCloud

## Архитектура

- **`/desktop`** — Tauri v2 + React 19 + Vite (фронтенд + нативная оболочка)

Backend, admin, landing, storage, streaming исключены — клиент использует публичный API оригинального проекта SoundCloud Desktop (`scdinternal.site`).

## Общие принципы

- **Не городить костыли и велосипеды.** Если есть библиотека для задачи — использовать её. Не писать свои реализации того, что уже решено.
- **Производительность по умолчанию.** Думать о ре-рендерах, подписках, памяти. Если можно сделать через DOM ref вместо React state — делать через ref. Если можно избежать лишнего запроса — избегать.
- **Минимум кода.** Не добавлять абстракции "на будущее", не рефакторить то что не просят, не добавлять docstrings/комментарии к коду который не менялся.
- **Не ломать существующее.** Любое изменение должно сохранять текущий UI/UX.
- **Язык общения — русский.**
- **НЕ использовать агентов для написания кода.** Писать код самому напрямую.
- **Действовать быстро.** Не тратить токены на лишние размышления.

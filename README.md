## Что это

**EzzCloud** — нативный десктоп-клиент SoundCloud с упором на стабильность и UX.

- Нативная оболочка: **Tauri v2 + Rust**
- Интерфейс: **React 19 + Vite + Tailwind**
- Поддержка: **Windows / Linux / macOS**
- Автообновления через GitHub Releases

---

## Установка

Скачайте последнюю версию: https://github.com/sxftezz-png/EzzCloud/releases/latest

- **Windows** — `EzzCloud_x.x.x_x64-setup.exe`
- **Linux** — `.deb` / `.rpm` / Flatpak
- **macOS** — `.dmg`

---

## Сборка из исходников

```bash
git clone https://github.com/sxftezz-png/EzzCloud.git
cd EzzCloud/desktop
pnpm install
pnpm tauri build
```
